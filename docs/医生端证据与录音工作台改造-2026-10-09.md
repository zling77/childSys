# 医生端证据与录音工作台改造

日期：2026-10-09。当前医生端提示版本：clinician-grounded-1.4。这是本地研究原型的开发记录；本次模型调用与浏览器验证均使用模拟病例，未验证临床有效性。量表关联按用户最新回复暂缓，没有新增量表计分、映射或阈值解释。

## 新的阅读顺序

1. 病例概览：患者基本信息、来源和问答数量、AI材料整合结论、风险与核实线索、分类概览、信息缺口。
2. 分类证据：主诉与具体表现、时间与变化过程、学习生活与场景、睡眠／食欲／躯体、背景与既往情况、安全线索与支持。可按来源筛选或搜索，分类和完整输入可折叠。
3. 问答与录音：每题都有原始录音按钮、来源、系统问题、可折叠的文字回答和关联证据。
4. 差异与核实：保留原规则版的分歧、时序、修正链及医生核实功能。
5. 材料与历史：来源会话关联、医生补充、报告比较、完整采集记录和附件。原有详细信息保留。

窄屏病例队列默认收起，桌面默认展开。旧规则摘要、报告保存和历史回看放在概览页的折叠区域；接入前后对照保留在AI总结的详细区域。

## 原始语音如何逐题播放

新问诊从展示当前问题开始记录客户端时间，到提交回答时标记结束；等待服务器或模型响应的时间不计入该回答窗口。主诉是第1题。成功提交后才保存标记，随后开始下一题。全程媒体上传时携带问题轮次、起止毫秒和录制开始时间。

服务端把轮次绑定到本会话真实存在的QA编号，拒绝不存在的问题、重复标记、重叠窗口、负时间和超出文件范围的窗口。SQLite第6版迁移只增加媒体时间线字段，旧数据保留。

播放优先级：本题独立附件 → 全程媒体中已记录的本题时间窗 → 标明“整段回放（未定位本题）”的旧全程记录。没有附件时显示不可用的“无原始录音”。原文件保留，可下载；音频直接播放，视频通过原音轨回放并保留画面。同一时间只播放一个播放器。

时间窗覆盖问答过程，可能包含提问播报与停顿，尚未实现逐词或逐句ASR对齐。原始语音用于医生核对，系统没有新增声学风险判断。

本次改造前数据库有47条问答，媒体附件为0。文字转写无法还原缺失的录音。开发模拟病例同样未伪造真人录音；播放验证使用独立临时数据库中的合成WAV与真实浏览器编码的合成WebM视频，测试后不留在当前病例中。

## AI总结和风险标签

仍由a001-1-cpolar的qwen3.5:9b负责证据抽取、关系初判、医生版表达三个阶段。医生版增加integrated_assessment栏目，将主要困扰、功能影响、安全线索和支持资源整合为带证据引用的材料结论。未通过校验的表述不会作为模型结论；缺课分歧等事项会以带双方引用的原文提示保留，并标明回退来源。

风险标签来自原话线索和证据关系，分为“已报告线索”“待核实”“否认陈述”“未观察到”“候选分歧”。不计算高／中／低风险等级，也不把缺失或未观察到当作排除风险。展示完整原始回答，保留行动、准备等限定语，避免拆句后遗漏语境。单独出现“上学日”等词不能形成明确功能影响标签。来源提供者与转述对象分别标明。

规则证据和模型证据仍可分别追溯；显示时只合并同来源、同轮次、同主题的重复陈述。陈述数量不能解释为模型准确率。当前模型候选的原文可打开查看；医生核实与纠正仍在原规则证据中单独保存，模型候选不会自动成为医生确认。过期模型报告明确提示，且不混入当前分类与风险标签。

引用定位、字段和有限范围校验不能证明语义蕴含、抽取完整性或临床正确性。数字校验目前采用有限字符串检查：把原文中文数字转换成阿拉伯数字也可能被拒绝，属于可能的保守误拒，不应一概称为模型编造。
