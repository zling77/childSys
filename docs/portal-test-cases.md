# 三端门户验收测试用例

## 运行方式

```bash
npm run test:portals
```

测试会启动独立的 `4276` API 和 `5276` Web 服务，使用临时 SQLite 数据库，关闭外部 LLM 调用，并使用本机 Chrome 的无头模式。不会修改正式 demo 数据，也不会消耗 DeepSeek API 额度。

## 家长端

| 编号 | 场景 | 预期结果 |
|---|---|---|
| G-01 | 从总入口进入家长端 | 路由和家长端标题正确 |
| G-02 | 页面首次进入 | 不自动播放语音；用户可手动播放/停止 |
| G-03 | 填写基本信息和知情同意 | 未完成必要签署前不能继续；完成后统一进入设备自检 |
| G-04 | 主诉入口 | 无固定症状主诉选项，支持自由口述/文字兜底 |
| G-05 | 播报期间点击语音输入 | 播报立即停止，语音识别开始 |
| G-06 | 提交主诉 | 创建会话并生成一轮一个问题的动态问诊 |
| G-07 | 提交一轮回答 | 对话记录增加，下一问发生更新 |
| G-08 | 播报期间开始原始录音 | 播报立即停止；录音进行中禁止提交，避免录音丢失或归错轮次 |
| G-09 | 拒绝音视频权限 | 显示可读的权限处理提示，页面不抛出脚本异常 |
| G-10 | 未授权保存音视频 | 仍检测语音所需麦克风，但不请求摄像头权限 |
| G-11 | 麦克风检测失败 | 允许改用自动展开的文字输入继续，不阻断预问诊 |

## 儿童端

| 编号 | 场景 | 预期结果 |
|---|---|---|
| C-01 | 从总入口进入儿童端 | 独立 `/child` 路由和儿童化文案正确 |
| C-02 | 回答者身份 | 固定显示儿童本人回答 |
| C-03 | 知情同意 | 由监护人完成签署后才能继续 |
| C-04 | 主诉和动态追问 | 使用“你/你的”，不出现“您/家长/孩子”等成人问法 |
| C-05 | 问题边界 | 每轮只出现一个问号、只问一件事 |
| C-06 | 回答提交 | 使用儿童端按钮文案并进入下一轮 |

## 医生端

| 编号 | 场景 | 预期结果 |
|---|---|---|
| D-01 | 医生端入口 | 与家长/儿童端使用同一全局侧栏和视觉系统 |
| D-02 | 首屏信息顺序 | 患者概览、结构化摘要、需优先核实、来源差异优先展示 |
| D-03 | 内部信息边界 | 不显示 Agent 执行、策略日志和模型审计 |
| D-04 | 状态措辞 | 使用“已采集”，不使用可能过度确定的“已确认” |
| D-05 | 追溯明细 | 时间线、证据原文、覆盖状态默认折叠且可展开 |
| D-06 | 音视频附件 | 无记录时不显示附件版块 |
| D-07 | 队列自动刷新 | 医生切换病例后，3 秒刷新不会跳回首条 |
| D-08 | 演示工具 | 生成/清空演示数据默认折叠，降低误触风险 |
| D-09 | 问答输入追溯 | 每轮以稳定 QA ID 关联系统提问和对应回答，并在同一卡片展示 |
| D-10 | 多来源输入 | 只有存在两个及以上来源时显示“多源问答时间线”，并分别统计监护人、患儿等来源 |

## 通用与数据安全

| 编号 | 场景 | 预期结果 |
|---|---|---|
| X-01 | 三端入口 | `/guardian`、`/child`、`/clinician` 均可直接访问 |
| X-02 | 测试数据 | 测试使用模拟内容和临时数据库 |
| X-03 | 模型调用 | 门户 E2E 测试关闭外部模型，不发送患者信息 |
| X-04 | 回归 | 核心规则、Acceptance、数据安全和生产构建继续通过 |
| X-05 | 隔离性 | 浏览器测试结束后自动关闭临时服务并删除临时数据库和媒体目录 |
